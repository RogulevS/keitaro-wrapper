# Обёртка над Keitaro

Локальный сервис на FastAPI и SQLAlchemy. Он создаёт кампанию в трекере и правит офферы в уже существующей кампании. В Keitaro изменения офферов уходят только по кнопке Push to Keitaro.

## Что делает создатель

Форма принимает название, гео-коды (`AU` или `MX, RO`) и оффер. Домен, группа и источник выбираются из API. Если ничего не выбрано раньше, предпочитается запись с именем `FORTESTS`, иначе берётся первая.

Кампания создаётся так:

- ротация потоков по позиции;
- модель затрат CPC, стоимость 0 USD, галка «из параметра cost»;
- первый поток `regular`: фильтр страны на указанные гео, редирект на `https://google.com`;
- второй поток `default`: выбранный оффер со долей 100%.

Поток без офферов в редакторе показывается как поток. Куда он редиректит и какие у него фильтры, интерфейс не рисует.

## Что делает редактор

1. **Fetch streams** читает потоки кампании из Keitaro.
2. **Add** добавляет оффер только локально. Активные доли заново делятся так, чтобы сумма была 100. Закреплённый вес не меняется, остаток делится поровну между остальными. Поток становится жёлтым.
3. **Remove** не стирает строку: оффер сереет, его доля 0. После публикации он пропадает из Keitaro, но остаётся в архиве.
4. **Bring back** возвращает серый оффер в расчёт и снова делает поток жёлтым.
5. **Cancel** откатывает несохранённые правки. Оффер, который добавили и ещё не публиковали, удаляется из локальной базы.
6. **Push to Keitaro** отправляет только активные офферы и их веса.
7. Если оффер удалили в самом Keitaro, следующий Fetch streams не стирает его у нас, а помечает серым, как после Remove.
8. **Pin** фиксирует вес. Следующие добавления и удаления пересчитывают только незакреплённые доли.

Целые проценты не всегда делятся нацело. Первые офферы в списке получают остаток, поэтому три оффера — это 34, 33 и 33, а не три раза по 33.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` укажите корень трекера и ключ из Keitaro (Профиль → API ключи):

```bash
KEITARO_BASE_URL=https://your-tracker.example
KEITARO_API_KEY=paste-api-key
DATABASE_URL=sqlite:///./keitaro.db
```

Миграции и сервер:

```bash
alembic upgrade head
uvicorn app.main:app --reload
```

Интерфейс: http://127.0.0.1:8000

Адрес и ключ можно также ввести на странице «Доступ». Значения из `.env` записываются в базу только если там ещё пусто. Файл `keitaro.db` не коммитится.

Проверка без трекера:

```bash
pytest
```

## База

SQLite хранит доступ к трекеру, локальную копию потоков и черновик весов. Таблицы: `tracker_settings`, `local_campaigns`, `local_streams`, `stream_offers`. Откат миграции: `alembic downgrade base`.
